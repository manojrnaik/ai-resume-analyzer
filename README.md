# AI Resume Analyzer (Gradio + Google Gemini API — Free)

A full-stack AI Resume Analyzer using **Google Gemini API** and **Gradio** UI.  
Fully free and mobile-friendly, deployable on **Hugging Face Spaces**.

## Features
- ATS Score
- Missing Skills Analysis
- Grammar & Writing Issues
- Summary Suggestions
- Live demo for recruiters

## How to Deploy
1. Push this repo to GitHub
2. Go to [Hugging Face Spaces](https://huggingface.co/spaces) → New Space → Import from GitHub
3. Set environment variable `GEMINI_API_KEY` in Space settings
4. Deploy → get live URL

## Tech Stack
- Python Flask alternative: Gradio
- Google Gemini API
- GitHub + Hugging Face Spaces
